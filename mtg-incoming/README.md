# HappyHomarid MTG Incoming Intake

This directory is the raw intake boundary for Commander deck candidates.

## Rule
Voice first. Structure second. Cards later.

Biggie or his wife may submit a phone voice-to-text capture. The raw transcript is preserved as the source record. Machine processing may normalize spelling and extract fields, but must not invent inventory, condition, price, commander, or availability.

## Pipeline

PHONE VOICE -> RAW TEXT -> NORMALIZE -> DECK RECORD -> CATALOG -> MTG CAROUSEL

A deck does not require a complete card scan before becoming a catalog candidate.

After a real purchase, fulfillment performs the deeper physical verification and personalization work.

## Minimum intake

- deck name
- commander
- rough value or price band
- strategy/theme when known
- colour identity when known
- physical location
- availability
- optional photo/decklist

## Status

RAW -> NORMALIZED -> NEEDS_REVIEW -> READY -> PUBLISHED -> SOLD/VERIFY -> FULFILLED
